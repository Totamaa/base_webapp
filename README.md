# Base webapp

This project is a basic template for a full stack application using Vue.js for the frontend, FastAPI for the backend, and PostgreSQL for the database. The project is containerized using Docker and Docker Compose.

## Technologies

- **Frontend**: Vue.js
- **Backend**: FastAPI
- **Database**: PostgreSQL
- **Containerization**: Docker and Docker Compose
